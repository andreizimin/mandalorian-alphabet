# Fonts

## mando-af-regular.woff2

- **Font:** Mando AF Regular, version 002, by AurekFonts. Draws the Mandalorian alphabet as it appears in *The Clone Wars* and *The Mandalorian*.
- **License:** CC0 1.0 (public domain), as stated in the font's own name table. No attribution required; credited here anyway.
- **Source:** `MandoAF/MandoAF-Regular.otf` in https://github.com/AurekFonts/AurekFonts.github.io (SHA-256 of the OTF: `0dc7251354f0141dfbd7a66613d65864ec34f0bd10f07c87577b8a27c797a635`).
- **Conversion:** OTF to WOFF2 with fontTools, no glyph changes.

All 26 letters have distinct glyphs, and each capital draws the same shape as its lowercase letter.
